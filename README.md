# 🧮 Numerical Methods Solver

A Python GUI application designed to solve numerical methods problems بسهولة وسرعة, with a simple and user-friendly graphical interface.

## ✨ Features

The application supports the following numerical methods:

### Linear Systems
- **Doolittle Method**
- **Thomas Method**
- **Jacobi Method**
- **Gauss-Seidel Method**

### Root Finding Methods
- **Bisection Method**
- **False Position Method**
- **Newton-Raphson Method**
- **Secant Method**
- **Fixed Point Iteration Method**

## 🛠️ Technologies Used

- Python
- Tkinter (Graphical User Interface)
- SymPy

## 📋 Requirements

- Python 3.12 or newer
- Required Python packages listed in `requirements.txt`

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd Numerical_Methods_Solver
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```
